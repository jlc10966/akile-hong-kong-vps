## 1Gbps 端口能不能跑满？先算流量这道墙

能跑满，但只能短时间跑满。香港 HKLite 的 1Gbps、2Gbps、5Gbps 指的是端口速率，实际可用带宽由月流量除以时间决定。把每档流量摊到 30 天，得到的平均持续带宽是这样的：

- 2.5TB → 平均约 7.7Mbps
- 5TB → 平均约 15.4Mbps
- 10TB → 平均约 30.9Mbps
- 30TB → 平均约 92.6Mbps

也就是说，HKLite-Mini 标着 1Gbps，一个月里平均只能跑 7.7Mbps 不断线。想真正用满 1Gbps，2.5TB 只够跑五个半小时左右（1TB 在 1Gbps 下约 2.2 小时跑完），跑完就限速 10Mbps 等下个月，或者花 10 元左右重置一次流量。

5Gbps 的 Pre-Mini 情况更极端：端口翻五倍，流量没变，除非你的业务就是短时突发（比如每天集中备份一次、偶尔拉个大文件），否则这 5Gbps 大部分时间是闲置的。

行业里“保证带宽”的通行口径是 99% 时间段达到标称值，共享端口在高峰期本来就会波动。谁承诺 100% 满速，谁在说假话。Akile 这套产品的约束条件很直白：端口给得大，流量卡得紧，超了限速不断网。你能接受这个模型，它就很划算；你想拿它当 7×24 满速下载机，第一周就会撞墙。

## 什么人不适合买 Akile 香港

要大陆访问稳定在 30–50ms 的，别买。HKLite 是普通线路，这个延迟水平需要 CN2 GIA、CMI 或三网优化线路，价格通常贵一倍以上。

要“独享带宽写进合同”的，也别买。这里卖的是端口速率加月流量，端口共享，超限限速，行业里所谓独享也只是“不被同节点用户挤占”，机房出口仍然是共享资源。

要无限流量的，同样不合适。五档全部按月流量计费，跑完限速 10Mbps。

放到市场里看，同样是二十几块钱，取舍方向完全不同：DigitalVirt 香港 Lite 21 元/月给 1Gbps 端口和 1000G 流量，CMI 线路 59 元/月给 200Mbps 和 1000G；恒创的大带宽云 50M 独享 16.5 元/月起，但月流量只有 500GB、超限限速 1Mbps。Akile 把预算压在流量上，那两家把预算压在线路和独享上。你要的是“一个月能跑几个 TB”，选 Akile；你要的是“大陆打开快且稳”，选优化线路那一边。
